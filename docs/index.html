BCV USD/VES Rate

Unofficial free API that scrapes the official rate from Banco Central de Venezuela daily at 8 PM Venezuela time.

loading…

Endpoints

  • GET rate.json — latest rate
  • GET history.json — array of all recorded rates

Example: fetch from JavaScript

fetch('rate.json')
  .then(r => r.json())
  .then(d => console.log(`1 USD = ${d.rate} VES (on ${d.date_ve})`));
